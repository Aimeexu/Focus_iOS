# 美国区 APP 分享功能设计对比

## 主流分享方式对比

### 1. Instagram 风格 ⭐⭐⭐⭐⭐
**特点**：简洁、直接、一个按钮搞定

```
┌─────────────────────────┐
│   [成就内容]             │
│                         │
│   [Share] 大按钮         │
└─────────────────────────┘
```

**优点**：
- 用户体验最简单
- 维护成本最低
- 适配所有平台

**代码示例**：
```swift
Button("Share") {
    // 直接打开系统分享面板
    presentShareSheet()
}
```

**适合**：大多数应用

---

### 2. Twitter 风格 ⭐⭐⭐⭐
**特点**：多个快速分享选项

```
┌─────────────────────────┐
│   [成就内容]             │
│                         │
│   ○    ○    ○    ○     │
│   FB   TW   IG   More   │
└─────────────────────────┘
```

**优点**：
- 快速访问常用平台
- 视觉上更丰富

**缺点**：
- 需要更多图标资源
- 维护成本稍高

**适合**：社交属性强的应用

---

### 3. Pinterest 风格 ⭐⭐⭐⭐⭐
**特点**：大按钮 + 小图标组合

```
┌─────────────────────────┐
│   [成就内容]             │
│                         │
│   [Share Achievement]   │  ← 主按钮
│                         │
│   ○  ○  ○              │  ← 快速选项
└─────────────────────────┘
```

**优点**：
- 主次分明
- 既简洁又灵活
- 用户体验好

**适合**：内容分享类应用（推荐！）

---

### 4. Reddit 风格 ⭐⭐⭐
**特点**：底部弹出式

```
从底部滑出：
┌─────────────────────────┐
│  Share to...            │
│  ○ Facebook             │
│  ○ Twitter              │
│  ○ Copy Link            │
│  ○ More Options         │
└─────────────────────────┘
```

**优点**：
- 符合 iOS 设计规范
- 可以自定义选项

**缺点**：
- 实现稍复杂
- 需要维护选项列表

---

## 美国区 TOP 应用的分享策略

### 游戏类（如 Candy Crush, Clash of Clans）
```swift
// 简单直接
[Share Your Score] → 系统分享面板
```

### 社交类（如 Instagram, TikTok）
```swift
// 多平台快速分享
[FB] [TW] [IG] [WhatsApp] [More...]
```

### 生产力类（如 Notion, Todoist）
```swift
// 一个主按钮
[Share] → 系统分享面板
```

### 健身类（如 Strava, Nike Run Club）
```swift
// 大按钮 + 统计信息
[Share Your Achievement]
包含：图片 + 数据 + 文字
```

## 推荐方案

### 方案 A：简洁版（推荐给你）✅
```swift
// 一个大按钮，打开系统分享面板
[Share Achievement]
```

**理由**：
- Focus 是生产力应用，用户关注专注本身
- 简洁符合应用调性
- 维护成本低
- 用户可以自由选择分享到任何平台

### 方案 B：增强版（如果需要更多功能）
```swift
// 主按钮 + 快速选项
[Share Achievement]  ← 主按钮
[Message] [Mail] [More]  ← 快速选项
```

**理由**：
- 提供快速访问常用选项
- 保持灵活性
- 视觉上更丰富

## 技术实现建议

### 1. 使用 UIActivityViewController（推荐）✅
```swift
let activityVC = UIActivityViewController(
    activityItems: [text, image],
    applicationActivities: nil
)

// 可选：排除不需要的选项
activityVC.excludedActivityTypes = [
    .addToReadingList,
    .assignToContact
]

// 可选：添加完成回调
activityVC.completionWithItemsHandler = { activity, success, _, _ in
    if success {
        // 记录分享统计
    }
}
```

### 2. 自定义分享内容
```swift
// 实现 UIActivityItemSource 协议
class ShareActivityItemSource: NSObject, UIActivityItemSource {
    func activityViewControllerPlaceholderItem(_ activityViewController: UIActivityViewController) -> Any {
        return ""
    }
    
    func activityViewController(_ activityViewController: UIActivityViewController, itemForActivityType activityType: UIActivity.ActivityType?) -> Any? {
        // 根据不同平台返回不同内容
        switch activityType {
        case .postToFacebook:
            return "Facebook 专用文案"
        case .postToTwitter:
            return "Twitter 专用文案（带 hashtags）"
        default:
            return "通用文案"
        }
    }
}
```
