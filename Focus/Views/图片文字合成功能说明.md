# 图片文字合成功能说明

## 功能概述
在分享成就时，可以在图片上叠加文字，生成一张包含图片和文字的合成图片用于分享。

## 实现方式

### 1. ImageTextComposer 工具类
位置：`Focus/Utils/ImageTextComposer.swift`

这是一个专门用于图片文字合成的工具类，提供了静态方法来在图片上添加文字。

**主要方法：**
```swift
static func composeImage(
    image: UIImage,
    text: String,
    textColor: UIColor = .white,
    fontSize: CGFloat = 24,
    position: TextPosition = .center,
    backgroundColor: UIColor = UIColor.black.withAlphaComponent(0.5),
    padding: CGFloat = 16
) -> UIImage?
```

**参数说明：**
- `image`: 原始图片
- `text`: 要添加的文字（支持换行符 `\n`）
- `textColor`: 文字颜色，默认白色
- `fontSize`: 字体大小，默认 24
- `position`: 文字位置（.top, .center, .bottom, .custom(CGFloat)）
- `backgroundColor`: 文字背景色，默认半透明黑色
- `padding`: 文字内边距，默认 16

### 2. Achievement 模型更新
在 `Achievement` 结构体中添加了 `shareText` 字段：

```swift
struct Achievement: Identifiable {
    // ... 其他字段
    let shareText: String? // 分享时显示的文字，由后台返回
}
```

### 3. ShareAchievementView 集成
在分享视图中，图片加载完成后会自动调用 `composeImageWithText` 方法进行文字合成：

```swift
private func composeImageWithText(image: UIImage) -> UIImage? {
    // 使用后台返回的文字，如果没有则使用默认文字
    let shareText = achievement.shareText ?? "We've been together\ncompleting 4 focus sessions\nGuess when I first met this little one?"
    
    return ImageTextComposer.composeImage(
        image: image,
        text: shareText,
        textColor: .white,
        fontSize: nil, // 自动根据图片大小计算
        position: .bottom,
        backgroundColor: UIColor.black.withAlphaComponent(0.7),
        padding: 20
    )
}
```

## 使用流程

### 当前实现（固定文字）
1. 用户点击分享成就
2. 系统加载成就图片（本地或远程）
3. 使用固定文字 "We've been together\ncompleting 4 focus sessions\nGuess when I first met this little one?" 进行合成
4. 生成合成后的图片用于分享

### 后台集成（动态文字）
当后台接口准备好后，只需要在创建 `Achievement` 对象时传入 `shareText` 参数：

```swift
let achievement = Achievement(
    id: 1,
    title: "专注大师",
    description: "连续专注30天",
    image: "hedgehog",
    isUnlocked: true,
    category: .calmFields,
    badgeNumber: 5,
    isRemoteImage: false,
    tab: .friends,
    shareText: "后台返回的分享文字\n支持多行显示"  // 从后台获取
)
```

## 文字格式建议

### 换行处理
使用 `\n` 来实现换行：
```
"We've been together\ncompleting 4 focus sessions\nGuess when I first met this little one?"
```

### 文字长度
- 建议每行不超过 30 个字符
- 总行数建议不超过 5 行
- 文字会自动居中对齐

### 样式定制
如需修改文字样式，可以在 `composeImageWithText` 方法中调整参数：
- `textColor`: 修改文字颜色（默认白色）
- `fontSize`: 修改字体大小（传 nil 则自动根据图片大小计算，推荐使用自动模式）
- `position`: 修改文字位置（.top 顶部, .center 居中, .bottom 底部）
- `backgroundColor`: 修改文字背景色（默认半透明黑色，alpha 0.7）
- `padding`: 修改文字内边距（默认 20）

### 自动字体大小
系统会根据图片宽度自动计算合适的字体大小：
- 计算公式：`fontSize = imageWidth / 15`
- 例如：600px 宽的图片，字体大小约为 40pt
- 这样可以确保文字在不同尺寸的图片上都有良好的显示效果

## 注意事项

1. **图片质量**：合成后的图片会保持原图的分辨率和质量
2. **性能**：图片合成是在主线程进行的，对于大图片可能会有轻微延迟
3. **文字显示**：文字会自动换行，但建议在后台控制好文字长度
4. **背景色**：默认使用半透明黑色背景，确保文字在各种图片上都清晰可见
5. **多语言**：shareText 应该根据用户语言设置返回对应的文字

## 测试建议

1. 测试不同长度的文字
2. 测试包含特殊字符的文字
3. 测试不同尺寸的图片
4. 测试本地图片和远程图片
5. 测试不同的文字位置（顶部、居中、底部）
