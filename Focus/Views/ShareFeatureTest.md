# 分享功能测试指南

## 测试前准备

1. 确保项目编译成功
2. 在真机或模拟器上运行应用
3. 确保已登录并有解锁的成就/海报

## 测试步骤

### 测试场景 1: 在成就页面分享
1. 打开应用，进入 "Friends" 标签页（成就页面）
2. 找到一个已解锁的成就（有图片显示的卡片）
3. 点击成就卡片
4. 应该弹出分享视图，显示：
   - 成就图片
   - 成就标题
   - 成就描述
   - 徽章数量（如果有）
   - Facebook 分享按钮
   - More 分享按钮
5. 点击 "Facebook" 按钮
   - 如果安装了 Facebook 应用，应该打开 Facebook
   - 如果没有安装，应该显示系统分享面板
6. 点击 "More" 按钮
   - 应该显示系统分享面板
   - 可以选择各种分享方式（微信、Twitter、邮件等）

### 测试场景 2: 在海报页面分享
1. 在成就页面，切换到 "Posting" 标签页
2. 找到一个已解锁的海报
3. 点击海报卡片
4. 应该弹出相同的分享视图
5. 测试分享功能（同上）

### 测试场景 3: 关闭分享视图
1. 打开分享视图
2. 点击右上角的 X 按钮
   - 分享视图应该关闭
3. 打开分享视图
4. 点击分享视图外的黑色背景区域
   - 分享视图应该关闭

### 测试场景 4: 远程图片分享
1. 选择一个使用远程图片的成就
2. 点击分享
3. 选择 "More" 分享
4. 等待图片下载
5. 系统分享面板应该包含图片和文字

### 测试场景 5: 本地图片分享
1. 选择一个使用本地图片的成就
2. 点击分享
3. 选择 "More" 分享
4. 系统分享面板应该立即显示，包含图片和文字

## 常见问题排查

### 问题 1: 分享视图不显示
- 检查是否点击了已解锁的成就
- 检查 `showShareView` 状态是否正确更新
- 检查 `selectedAchievement` 是否有值

### 问题 2: Facebook 分享不工作
- 检查设备是否安装了 Facebook 应用
- 如果没有安装，应该回退到系统分享面板
- 检查控制台日志

### 问题 3: 图片不显示
- 检查图片 URL 是否正确
- 检查网络连接
- 检查本地图片资源是否存在

### 问题 4: 系统分享面板不显示
- 检查是否正确获取了 rootViewController
- 检查控制台是否有错误日志
- 在真机上测试（模拟器可能有限制）

## 调试技巧

1. 在 Xcode 控制台查看日志输出
2. 使用断点调试分享流程
3. 检查 `isSharing` 状态变化
4. 验证分享内容的生成

## 性能测试

1. 测试多次快速点击分享按钮
   - 应该有防重复点击保护
2. 测试大图片的下载和分享
   - 应该有加载指示器
3. 测试网络不佳的情况
   - 应该有超时处理
