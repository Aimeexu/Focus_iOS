# 成就分享功能使用说明

## 功能简介

我已经为你的 Focus 应用添加了成就分享功能。现在用户可以在获得奖励（成就或海报）时，将其分享到 Facebook、Google 或其他社交平台。

## 新增文件

1. **ShareAchievementView.swift** - 分享视图组件
   - 位置: `Focus/Views/ShareAchievementView.swift`
   - 功能: 显示成就详情并提供分享选项

## 修改的文件

1. **PostingView.swift** - 海报视图
   - 添加了分享视图的 overlay
   - 点击海报时显示分享选项

2. **AchievementsView.swift** - 成就视图
   - 已经有分享功能的基础代码
   - 现在可以正常工作

## 如何使用

### 用户操作流程

1. **在成就页面**:
   - 进入 "Friends" 标签页
   - 点击任意已解锁的成就卡片
   - 弹出分享视图

2. **在海报页面**:
   - 切换到 "Posting" 标签页
   - 点击任意已解锁的海报卡片
   - 弹出分享视图

3. **分享选项**:
   - **Facebook 按钮**: 分享到 Facebook
     - 如果安装了 Facebook 应用，会打开应用
     - 如果没有安装，会显示系统分享面板
   - **More 按钮**: 显示系统分享面板
     - 可以分享到微信、Twitter、Instagram 等
     - 可以通过邮件、短信分享
     - 可以保存图片到相册

4. **关闭分享视图**:
   - 点击右上角的 X 按钮
   - 点击分享视图外的黑色区域

## 分享内容

分享时会包含以下内容：
```
我在 Focus 应用中获得了成就：[成就名称]！
[成就描述]
[成就图片]
```

## 技术特点

1. **无需第三方 SDK**: 使用 iOS 原生分享功能
2. **支持远程图片**: 自动下载远程图片后分享
3. **支持本地图片**: 直接从 Assets 读取图片
4. **优雅的 UI**: 半透明背景 + 卡片式设计
5. **流畅的动画**: 弹出和关闭都有平滑过渡
6. **iPad 适配**: 在 iPad 上以 popover 形式显示

## 注意事项

1. **网络连接**: 分享远程图片需要网络连接
2. **权限**: 首次分享可能需要用户授权
3. **Facebook 应用**: 
   - 如果用户安装了 Facebook 应用，会优先使用
   - 如果没有安装，会使用系统分享面板
4. **图片大小**: 大图片可能需要一些时间下载
