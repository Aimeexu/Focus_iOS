# 分享功能说明

## 功能概述
Focus 应用的成就分享功能，支持三种分享方式：

### 1. Facebook 分享 ⭐⭐⭐⭐⭐
- **使用 Facebook SDK 原生分享**
- 点击 Facebook 按钮后，直接打开 Facebook 原生分享对话框
- 用户可以添加评论、选择隐私设置、标记朋友
- 如果 Facebook 分享失败，自动回退到系统分享面板

### 2. Instagram 分享 ⭐⭐⭐⭐⭐
- **使用 Instagram Feed 分享**（动态）
  - 直接打开 Instagram 应用
  - 图片自动加载到编辑界面
  - 可以添加说明文字、滤镜、标签
  - 发布到 Instagram 动态
  
- **为什么不用 Stories？**
  - Instagram Stories URL Scheme 需要在 Facebook 开发者平台注册并通过审核
  - 需要将应用添加到 Instagram 白名单
  - Feed 分享更简单可靠，不需要额外配置

### 3. More 分享 ⭐⭐⭐⭐⭐
- **使用 iOS 系统分享面板**
- 支持所有已安装的应用：微信、Twitter、邮件、短信等
- 用户可以自由选择分享目标

## 技术实现

### Facebook SDK
```swift
import FBSDKShareKit
import FBSDKCoreKit

// 使用 ShareDialog 分享图片
let photo = SharePhoto(image: image, userGenerated: true)
let content = SharePhotoContent()
content.photos = [photo]

let dialog = ShareDialog(viewController: vc, content: content, delegate: nil)
dialog.mode = .automatic
dialog.show()
```

### Instagram Feed
```swift
// 使用 Document Interaction Controller
let documentController = UIDocumentInteractionController(url: imageURL)
documentController.uti = "com.instagram.exclusivegram"
documentController.annotation = ["InstagramCaption": "文案"]
documentController.presentOpenInMenu(...)
```

## 配置要求

### Info.plist
需要添加以下 URL Schemes：
```xml
<key>LSApplicationQueriesSchemes</key>
<array>
    <!-- Facebook -->
    <string>fbapi</string>
    <string>fbauth</string>
    <string>fbshareextension</string>
    
    <!-- Instagram -->
    <string>instagram</string>
    <string>instagram-stories</string>
</array>
```

### Podfile
需要安装 Facebook SDK：
```ruby
pod 'FBSDKCoreKit'
pod 'FBSDKLoginKit'
pod 'FBSDKShareKit'
```

## 分享流程

### Facebook 分享流程
1. 用户点击 Facebook 按钮
2. 预加载的图片已准备好
3. 调用 Facebook SDK 显示原生分享对话框
4. 用户编辑并发布
5. 完成

### Instagram 分享流程
1. 用户点击 Instagram 按钮
2. 检查 Instagram 是否已安装
   - ✅ 已安装 → 打开 Instagram Feed 编辑界面
   - ❌ 未安装 → 显示提示"请先安装 Instagram 应用"
3. 用户在 Instagram 中编辑并发布
4. 完成

### More 分享流程
1. 用户点击 More 按钮
2. 显示 iOS 系统分享面板
3. 用户选择目标应用
4. 完成

## 优化特性

### 图片预加载
- 在视图出现时自动预加载图片
- 避免分享时的等待时间
- 提升用户体验

### 智能回退
- Facebook 分享失败 → 系统分享
- Instagram Stories 失败 → Instagram Feed
- Instagram Feed 失败 → 系统分享

### 分享内容
- 优先使用后台返回的 `shareText`
- 如果没有，使用默认格式：
  ```
  🎉 我在 Focus 应用中获得了成就：[成就名称]！
  
  [成就描述]
  ```

## 使用方式

在任何需要分享的地方：
```swift
ShareAchievementView(
    achievement: achievement,
    isPresented: $showShareView
)
```

## Instagram Stories 分享说明

### 为什么不支持 Stories？
Instagram Stories URL Scheme (`instagram-stories://share`) 从 2020 年开始有以下限制：

1. **需要 Facebook 开发者平台注册**
   - 必须在 https://developers.facebook.com/ 注册应用
   - 需要添加 Instagram 产品
   - 需要配置 Instagram Basic Display

2. **需要白名单审核**
   - 应用需要提交审核
   - 或者在测试模式下添加测试用户
   - 审核周期较长

3. **配置复杂**
   - 需要配置 OAuth Redirect URIs
   - 需要配置 Deauthorize Callback URL
   - 需要配置 Data Deletion Request URL

### 当前方案：Instagram Feed
- ✅ 不需要白名单
- ✅ 不需要额外配置
- ✅ 更简单可靠
- ✅ 用户体验良好

### 如果你想启用 Stories
需要完成以下步骤：

1. 访问 https://developers.facebook.com/apps/4521478054746312
2. 添加 Instagram 产品
3. 配置 Instagram Basic Display
4. 提交应用审核
5. 等待审核通过

## 注意事项

1. **Instagram 需要在真机上测试**，模拟器无法测试 Instagram 分享
2. **Facebook SDK 需要正确配置** App ID 和 Client Token
3. **图片格式**：支持 PNG 和 JPEG
4. **图片大小**：建议不超过 5MB
5. **Instagram Feed 分享**：用户需要手动点击"分享"按钮完成发布
